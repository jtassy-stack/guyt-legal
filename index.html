GUYt — Politique de confidentialité

Dernière mise à jour : 12 octobre 2026

GUYt est une application macOS d’écriture de romans. Cette page explique quelles données elle traite, où elles vont, et ce que nous ne collectons pas.

Responsable du traitement

Pardon my French (« PMF »), éditeur de GUYt.
Contact : jtassy@pardon-my-f.com

Ce que GUYt ne fait pas

  • Pas de compte GUYt, pas de serveur GUYt : nous ne recevons ni vos textes ni vos clés.
  • Pas de publicité, pas de pistage, pas de mesure d’audience dans l’application.

Vos manuscrits

Vos textes restent en Markdown sur votre disque, dans le dossier que vous désignez. L’historique des versions est stocké dans ce même dossier. Rien n’est enfermé dans l’application et rien n’est envoyé à PMF.

Assistance par IA

Les agents d’écriture sont facultatifs. Lorsque vous les utilisez, les passages de texte nécessaires à votre demande sont envoyés au fournisseur d’IA que vous avez configuré :

  • Mistral AI (France, UE) par défaut ;
  • ou un autre fournisseur de votre choix, avec votre propre clé : Claude (Anthropic), OpenAI, Groq, Z.ai, Scaleway, OVHcloud, IONOS, OpenRouter.

Ces échanges sont régis par la politique de confidentialité du fournisseur choisi. Sur les Mac compatibles, un modèle embarqué (Apple) traite certaines demandes sans quitter l’appareil.

Clés d’API

Les clés que vous saisissez sont conservées dans le trousseau de votre Mac. PMF n’y a pas accès.

Synchronisation GitHub (facultative)

Si vous l’activez, votre manuscrit est envoyé dans un dépôt privé de votre propre compte GitHub, après autorisation de votre part. GitHub agit alors selon sa propre politique de confidentialité.

Recherche web et veille (facultatives)

La recherche documentaire contacte DuckDuckGo avec les termes que vous recherchez. La veille d’actualité contacte le service Celyn Actu. Ces fonctions ne s’exécutent que si vous les utilisez.

Vos droits

Comme PMF ne détient pas vos manuscrits, il n’y a pas de données à extraire ou à effacer chez nous. Pour toute question ou demande au titre du RGPD (accès, rectification, effacement, opposition), écrivez à l’adresse de contact ci-dessus. Vous pouvez aussi saisir la CNIL (cnil.fr).

Modifications

Cette politique peut évoluer avec l’application ; la date de mise à jour figure en haut de cette page.
